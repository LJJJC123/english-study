# 英语学习助手 · 高中同步 | 雅思口语

单文件网页应用：**纯前端、无后端、无需安装**。数据保存在浏览器本地（localStorage），不上传任何服务器。

## 在线访问

https://ljjjc123.github.io/english-study/

手机、电脑浏览器直接打开即可，建议「添加到主屏幕」当 App 用。

## 功能

| 模块 | 说明 |
|---|---|
| 学习看板 | 生词总数 / 今日已默写 / 今日待默写 / 错题数 / 近 7 天正确率 / 连续打卡 |
| 生词本 | 手动录入自动查释义；点击、划选、双击任意英文单词即可收录 |
| 高中英语 | 人教版（2019）必修 1-3 + 选择性必修 1-4，共 7 册 36 单元 2526 词（含美式音标） |
| 默写 | 英选中（进入即自动播放美音）/ 中默英（不提供读音）/ 混合；可按册、单元选范围 |
| 听写 | 自动读音（最多重听 2 次）→ 拼写英文 → 选择中文意思，两项都对才算对 |
| 错题本 | 错词自动收录，连续答对 2 次自动移出 |
| 雅思口语 | 三级难度、不同角色 Agent、语音对话、官方四项评分、逐句纠错 |
| 练习场 | 阅读 / 七选五 / 完形 / 语法填空 / 读后续写 / 作文；错题不入错题本 |
| 数据与设置 | 导出 JSON / CSV（可导 Anki）、导入恢复、AI 接口配置 |

## 说明

- 词表取自公开整理的人教版（2019）高中英语词表，已做清洗并补全美式音标；个别释义仍可能有录入偏差。
- **手机与电脑的数据各自保存在本机浏览器，不自动同步**；需要搬数据时用「数据与设置」导出 / 导入 JSON。
- 部署在 HTTPS 上，手机上雅思口语的 🎤 麦克风才能正常使用。
- AI 相关功能（练习场出题、作文批改、雅思评分）需在「数据与设置」里填自己的 OpenAI 兼容接口，密钥只存在本机浏览器。
