英语学习助手 · 网页原型 v0.17 使用说明

在线版（已部署，手机电脑都能开）：https://ljjjc123.github.io/english-study/

一、电脑上使用
1. 直接打开上面的网址最省事；也可以双击本文件夹中的 index.html（两种方式完全一样）。
2. 数据保存在浏览器本机，换浏览器或清缓存会丢失，请定期到「数据与设置」页导出备份。
3. 键盘快捷：默写 / 听写的输入框里按 回车 = 提交；判定出来后按 回车 = 下一题。
4. 注意：本地文件和在线版是两个网站，各自存一份数据，互不相通；认准一个用就行。

二、手机上使用
1. 用手机浏览器打开上面的网址即可（不用再传文件）。
   想更像 App：浏览器菜单里选「添加到主屏幕」，之后像点 App 一样打开。
2. 界面已做手机自适应：
   · 顶部标题栏与底部内容自动避开刘海 / 底部手势条；
   · 点进输入框时页面不会再被自动放大（iOS 的老毛病）；
   · 所有可点的按钮、选项都按手指大小做过校验。
   · 注：手机上的语音识别（口语🎤）与朗读对浏览器有要求，建议用 Chrome / Edge；iPhone 用 Safari 也可朗读。
   · 重要：打开网页后请先在页面上随便点一下。手机浏览器规定"必须先有用户操作，网页才允许自动朗读"，
     点过之后听写 / 英选中的自动读音才会出声。
3. 在线版是 HTTPS 的，手机上雅思口语的 🎤 麦克风可以正常使用（本地文件打开时很多手机会拦住麦克风）。
4. 手机和电脑的数据是各存各的，不会自动同步；要搬数据请用「数据与设置」导出 / 导入 JSON。

三、功能地图
· 学习看板：生词总数 / 今日已默写 / 今日待默写 / 错题数 / 近7天正确率 / 连续打卡 / 每日目标
· 生词本：手动输入自动查释义（已内置人教版全 7 册 2526 词）；练习场文章里点英文单词即可加入；
  在任意页面（雅思对话、报告、记录等都行）用鼠标划选或双击一个英文单词，也会弹出词卡，可一键加入
· 高中英语：已内置人教版（2019）必修 1-3 + 选择性必修 1-4 共 36 个单元；先选册、再选单元，下方按键按你选的范围开始默写 / 听写；也可导入自己的词表（每行：单词 | 音标 | 释义）
· 默写：范围可选「生词本 / 高中全册（先选哪一册，再选单元或整册）」；英选中（4选1，进入题目即自动播放美音，可点按钮重听）/ 中默英（不提供读音），确认后判分，错词入错题本
· 听写：范围同样可选单元；进入题目即自动播放读音（最多重听2次）→ 拼写英文 → 选择中文意思，两项都答对才算对；错词入错题本
· 错题本：错词自动收录，连续答对2次自动移出；支持重练/删除
· 雅思口语：初学/中级/高级三档，每次随机话题；支持语音对话（🎤）、考官自动朗读（美音）、结束生成报告与记录；另有「全真模考」：Part1（4 题，每题 45 秒）→ Part2（1 分钟准备 + 2 分钟陈述）→ Part3（4 题，每题 60 秒），全程倒计时、时间到自动进入下一步，结束直接出四项评分报告
· 练习场：阅读 / 七选五 / 完形 / 语法填空 / 读后续写 / 作文练习；每道题标注考点；练习场错题不入错题本，只在每场复盘
· 整套模考（练习场最后一个标签）：按浙江卷顺序把阅读→七选五→完形→语法填空→读后续写排在一页，每节单独提交，底部实时汇总客观题得分与正确率；读后续写不自动判分，可单独交 AI 批改
· 考点专项（练习场顶部）：点一个考点（如非谓语动词）会跳到对应题型并高亮该考点的题；配了 AI 就按这个考点出新题。答错会累计，结果显示「累计错得最多的考点」
· 数据与设置：导出/导入备份、导出CSV（可导Anki）、每日目标、AI接口设置、发音音色与语速

四、AI 功能如何开启（可选）
1. 进入「数据与设置」→ AI 设置，填入 OpenAI 兼容接口：
   接口地址（如 https://api.openai.com/v1 或 DeepSeek 等兼容地址）、API Key、模型名；
2. 点击「连接测试」通过后即可使用：生词联网查询、练习场AI出题、作文/续写AI批改、雅思逐句纠错与四项评分（均带双Agent互检）；
3. 密钥只保存在你本机浏览器，不会上传到任何其他地方。

五、本次更新（v0.17 · 重做 UI 颜色：中性石墨 + 琥珀）
上一版我把中性灰全部往暖黄轴偏，想做出"台灯下的书桌"，结果整页变成了**棕泥地**——
大面积近棕的暗面读起来是"脏"，不是"高级"。这一版换掉的是**底**，不是重点色。

· 底色改成**中性近黑**（#0c0d0f，只带一丝冷，肉眼几乎看不出蓝），卡片与输入框仍按亮度分三层。
  现在的观感是干净的深灰，不再是棕黄。
· 焦点色从黄铜换成**琥珀**（#edae3b）——比原来更亮更干净，只出现在章节标记、当前项、
  进度条、选中边框这些很细的地方，实测占屏 0–0.1%。
· 五张空状态插画按同一支笔重新上色成新琥珀色（原来的黄铜比它暗一档，摆在一起会不一致）。
  顺带文件小了一半。
· 文字对比度反而更好了：最差 7.04:1（上一版 5.08:1），九页低对比 0 处。

以下为 v0.14 更新（视觉方向重做：从「AI 味」到「台灯下的书桌」）：
上一版只是把界面变深，配色还是那套最常见的靛紫，所以看着廉价。这一版是重做设计方向：
· 底色换成暖石墨（锚定色相 75°，接近 #110f0c），不是发蓝的冷灰，也不是纯黑。
  卡片、输入框三层暗面每层拉开 4% 亮度——深色下阴影几乎看不见，靠亮度差分层才可靠。
· 强调色换成黄铜（#e0b76c），而且**只当荧光笔用**：章节小方块、当前项、聚焦环、
  进度条、页签底边。实测 9 个页面里强调色占屏 0–0.7%（此前靛紫占屏三成以上）。
· 主按钮改成"暖纸白底 + 深字"，不再是彩色大块。深色主题下亮底深字才显高级。
· 首页六个等大 KPI 方块改成一条带发丝分隔的**数据条**（规格表式排布），
  需要突出的「今日待默写」改用顶部一道黄铜细线标记，不再整格铺色。
· 桌面端模块卡的按钮不再通栏（那是手机模式），左对齐自适应宽度，不再像两块大板子。
· 去掉了毛玻璃顶栏、进度条的紫→紫渐变；正确/错误改成柔和的苔绿与珊瑚红，
  不再刺眼。页面标题前加了一枚黄铜小方块作为章节标记。
· 顺手兑现一个欠账：正确率折线图的线色原来写死在 JS 里，现在也走配色变量，
  样式规则里再无硬编码色值（只剩 theme-color 一处，那个位置必须写具体色值）。
· 数据仍在本机浏览器，与旧版本完全兼容，不需要重新导入。

以下为 v0.11 更新：

   雅思模考按钮与麦克风按钮已改为向上查找最近的按钮。

以下为 v0.10 更新：
这轮除了改界面，还揪出并修掉一个我自己上一版留下的错：
· 【修错】上一版做间距归一的正则把 margin:10px 0 这类值拼成了 margin:10px0（10 条声明），
  浏览器会整条忽略它们，卡片的上下间距是失效的。已全部修正。
· 顺带发现：卡片在网格里时，margin 和 gap 会叠加成 30px；现在网格内的卡片外边距归零，由 gap 统一控制。
按可用性原则（NN/g 十大启发式 + Laws of UX）改的六处：
① 同类信息等宽——看板 6 个指标原来是「4 列 + 2 列」两种尺寸，现在统一成一排等宽（窄屏 3 列 / 手机 2 列）。
② 突出该做的事——「今日待默写」用主色标出来。其余是结果指标，它是行动项，视觉层级应当不同。
③ 空状态不摆空框——没有默写记录时，正确率图表整块隐藏，只留一行说明；有数据才画。
④ 去掉重复信息——「连续打卡」原来在标题和图表行各出现一次，现在只留一处。
⑤ 描边与阴影二选一——卡片只用描边，阴影留给弹窗、抽屉这类真正悬浮的层（原来两者叠加，阴影淡到看不见）。
⑥ 间距节奏——卡片外边距统一为 12px（4pt 栅格）。

  可以用 Tab 聚焦、回车或空格触发，选中状态同步 aria-pressed（实测：空格选中选项后「确认提交」自动可用）。
